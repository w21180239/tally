# Security policy

Report vulnerabilities privately through [GitHub security advisories](https://github.com/w21180239/tally/security/advisories/new), not in a public issue.

Relevant reports include a way to make tally write to a transcript file, to open a network connection other than the weekly pricing-page request (or any request when `priceUpdate` is false), to send repository names, titles, paths or commands off the machine at the default `shareDetail`, to read or write files outside the Claude config folder, the sync folder and the Herdr folder, or to execute a command from data in a transcript or in a synced file.

Only the latest release is supported. Expect a first reply within a week.
